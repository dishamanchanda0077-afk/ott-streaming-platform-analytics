# OTT Streaming Platform Analytics

An end-to-end analytics case study exploring user engagement, content performance, recommendation effectiveness, and viewing behavior using Python, SQL, Power BI, and DAX.

## Tools Used

- Python
- SQL
- Power BI
- DAX

## Project Workflow

Raw Data
→ Python (Cleaning & EDA)
→ SQL (Analysis & Aggregations)
→ Power BI (Dashboard & KPIs)
→ Business Insights

## Dashboard Pages

1. Executive Overview
2. User Behavior Analysis
3. Content & Recommendation Analytics
